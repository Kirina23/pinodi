# Pinodi 1.0.0 (сборка — номер от Codemagic) → App Store 1.0.0: разбор (архив №20)

Первая версия приложения **Pinodi: Photo To-Do List** — задачи в виде фото. На иконке — обезьянка Pinodi с фотографией.
Внутри проекта осталось рабочее имя Snapdo (папка `ios/Snapdo`, Xcode-проект и схема `Snapdo`, модули `modules/snapdo-*`) — пользователи его не видят, сборку это не трогает.
Bundle id: `com.pinodi.app`. iPhone + iPad (портрет и альбом), учтён iPhone Duo.
Языки: русский и английский (берётся язык телефона). Pro — подписка: месяц и год.

---

## Сначала: что сделать руками

Это новое приложение, поэтому один раз нужно завести всё с нуля. Дальше будет как со Slay: распаковала → push → TestFlight.

**Архив №20 заменяет №19.** Если репозиторий `pinodi` уже создан: распакуй архив поверх в той же папке, сделай commit + push — и дальше шаги 2–4 уже с новым ID `com.pinodi.app`. Если с №19 в Apple успели завести `com.slay.pinodi` — это больше не нужно: App ID можно удалить (Identifiers → `com.slay.pinodi` → Remove), профиль тоже.

**Что поменялось в №20:** bundle id **`com.pinodi.app`** (было `com.slay.pinodi`) и коды подписок **`com.pinodi.app.pro.*`** — Pinodi отдельное приложение, без чужого имени в ID. Больше ничего.

Что в №19 (по сравнению с черновиками): имя **Pinodi**, bundle id `com.pinodi.app`, коды подписок `com.pinodi.app.pro.*`, иконка с обезьянкой (светлая, тёмная, тонированная), анимация при запуске (`src/overlays/LaunchIntro.tsx`, `introTiming.ts`), группа переменных в Codemagic теперь `pinodi_signing`.

**1. Репозиторий на GitHub**
1. github.com → **New repository** → имя `pinodi`, **Private** → Create.
2. Открой папку, где лежат твои проекты, в терминале VS Code и выполни:

        unzip -o pinodi-1.0.0-20.zip
        cd pinodi
        git init -b main
        git add -A && git commit -m "1.0.0: первая версия Pinodi"
        git remote add origin https://github.com/<твой-логин>/pinodi.git
        git push -u origin main

**2. developer.apple.com (Certificates, Identifiers & Profiles)**
1. **Identifiers → +** → App IDs → App → Description `Pinodi`, Bundle ID **Explicit** `com.pinodi.app` → Continue → Register. (In-App Purchase включён сам.)
2. **Profiles → +** → Distribution → **App Store Connect** → App ID `com.pinodi.app` → сертификат тот же **Apple Distribution**, что у Slay → имя `Pinodi App Store` → Generate → **Download** (файл `.mobileprovision`).

**3. App Store Connect**
1. **Apps → + → New App**: iOS, имя `Pinodi: Photo To-Do List`, основной язык English (U.S.), Bundle ID `com.pinodi.app`, SKU `pinodi`.
2. Pinodi → **Monetization → Subscriptions** → создай группу `Pinodi Pro` и в ней три подписки:

   | Reference name | Product ID | Длительность |
   |---|---|---|
   | Pro Yearly | `com.pinodi.app.pro.yearly` | 1 год |
   | Pro Monthly | `com.pinodi.app.pro.monthly` | 1 месяц |
   | Pro Yearly Offer | `com.pinodi.app.pro.yearly.offer` | 1 год |

   **Pro Yearly Offer** — тот же год Pro, но дешевле: его покупают только на экране разовой скидки (через 3 недели без Pro). Цену ставишь сама — приложение само посчитает «−N %» от обычного года. Например, год $19.99 → акция $9.99 = −50 %. Пробный период для неё не добавляй.

   В каждой: цена, локализация (ru и en): Display Name `Pinodi Pro`, Description — тексты в документе ASO, и скриншот для ревью (прикладываю `Pinodi-paywall-для-ревью.png` — с новым именем; цены на нём примерные — когда сборка будет в TestFlight, лучше заменить своим скриншотом).
   Для годовой можно добавить **Introductory Offer → Free → 1 week** — приложение само покажет «7 дней бесплатно» на плитке «Год» и кнопку «Попробовать 7 дней бесплатно».
   Моё предложение по ценам: месяц **$2.99**, год **$19.99** (выгода ≈ 44 %). Решаешь ты — приложение берёт цены из App Store само.
3. Соглашение Paid Apps уже действует (общая команда со Slay) — ничего делать не нужно.

**4. Codemagic**
1. **Add application** → GitHub → `pinodi` → он сам найдёт `codemagic.yaml`.
2. Teams → **Environment variables** → новая группа **`pinodi_signing`** с тремя переменными, все **Secret** (значения те же, что в группе Slay):
   `APP_STORE_CONNECT_ISSUER_ID`, `APP_STORE_CONNECT_KEY_IDENTIFIER`, `APP_STORE_CONNECT_PRIVATE_KEY`.
3. **Settings → codemagic.yaml settings → Code signing identities → iOS provisioning profiles** → загрузи `Pinodi App Store.mobileprovision` (в том же аккаунте Codemagic, где приложение `pinodi`). Без этого сборка падает сразу с ошибкой «No matching profiles found for bundle identifier "com.pinodi.app"».
   У загруженного профиля сертификат должен быть отмечен как загруженный. Если написано «Certificate: Not uploaded» — во вкладке **iOS certificates** загрузи `.p12` того же Apple Distribution, что у Slay (с паролем). Это нужно, если Slay собирается в другом аккаунте Codemagic.
4. Нажми **Start new build** (или просто push в `main`).

**5. Ссылка на политику конфиденциальности**
Политика уже на твоём сайте: `https://www.brauny.pro/privacy-snapdo.html` — этот адрес стоит в приложении (☰ → «Политика конфиденциальности») и его же вписываешь в App Store Connect → App Privacy → Privacy Policy URL. На самой странице поменяй имя Snapdo на Pinodi (адрес можно оставить прежним).

**Что может упасть в первой сборке.** Модули покупок `modules/snapdo-store` (StoreKit 2) и уведомлений `modules/snapdo-notify` (Swift) здесь скомпилировать нельзя — первый лог Codemagic и есть их проверка. Уведомления — локальные (планируются на самом iPhone): включать Push Notifications в App ID и пересоздавать профиль **не нужно**. Если сборка красная: скажи, на каком шаге, и пришли 10–20 строк вокруг первого `error:`. Исправлю и пришлю новый архив или одну строку для VS Code.

**Внизу меню ☰** видно `Pinodi 1.0.0 (N)` — по этой строке понятно, какая сборка на телефоне.

## Что изменилось по сравнению с HTML-прототипом

Дизайн перенесён 1:1: цвета, шрифты (Georgia + системный), отступы, размеры карточек, тексты.
Ниже — что я улучшила после проверки UX/UI и почему.

**Значки**
- Все значки — **системные SF Symbols** от Apple (те же, что в «Фото», «Заметках», «Напоминаниях»). Они чётче нарисованных, сами подстраиваются под крупный шрифт и тёмные места, галочка «подпрыгивает» при выполнении. Активная вкладка теперь залитая — так делает iOS.
- **Иконка приложения** — в сборке **обезьянка Pinodi с фотографией** (твой рисунок «02 · Фото», перерисован в векторе: `design/app-icon/pinodi/`). Есть светлый, тёмный (тёмно-синий фон) и «тинт»-вид (iOS 18+). Файл для App Store Connect — `Pinodi-icon-1024.png`. Прежние мозаики лежат в `design/app-icon/` как история.
- **Анимация при запуске** (№19): экран запуска — та же иконка на светлом фоне; затем обезьянка кивает, и фото у неё в руках вырастает и превращается в доску. 0,6 секунды; при «Уменьшении движения» — просто плавное появление. Файлы: `src/overlays/LaunchIntro.tsx`, `introTiming.ts`.

**Удобство (UX)**
1. **Долгое нажатие на карточку** открывает меню как в «Фото»: фото целиком и действия. Раньше «Изменить» и «Удалить» прятались в два нажатия (задача → «…»).
2. Жест «развести двумя пальцами» на карточке убран: на iPhone он мешает прокрутке, и его никто не находит. Фото целиком показывает долгое нажатие, а зум — просмотр фото.
3. **Примеры не съедают бесплатный лимит.** Раньше 6 из 10 бесплатных мест сразу были заняты примерами — новичок упирался в Pro после 4 своих задач.
4. В Pro убрала пункт **«Без рекламы»**: рекламы в приложении нет вообще, обещать её отключение — вводить в заблуждение (Apple может придраться на ревью).
5. Pro теперь настоящая подписка: год (по умолчанию, с бейджем «Выгода N %» и ценой в месяц) и месяц, «Восстановить покупки», «Условия» и «Конфиденциальность» — всё, что требует Apple.
6. **«Удалить список»** — раньше списки можно было создать, но не удалить. Задачи остаются во «Всех задачах», есть «Вернуть».
7. Подсказка в режиме размеров: «Перетащи за крестик» → «Тяни за стрелки…» — «крестик» путали с «закрыть».
8. **Дата** — системная кнопка-календарь Apple; **список** — раскрывающийся выбор как в «Настройках» вместо веб-меню.
9. «Сохранить PNG» убрала: в меню «Поделиться» у iOS уже есть «Сохранить изображение».
10. **iPhone в альбомной ориентации** — 4 колонки вместо 3: раньше на экране помещался один ряд.
11. Шторки закрываются **свайпом вниз**, как в iOS; на iPad — карточкой по центру.
12. Файлы — до **200 МБ** (35 МБ было ограничением веб-версии). PDF и документы открываются системным просмотром.
13. Фото на весь экран — родной зум iOS (плавный, с пружиной).
14. Лёгкая **вибрация** при выполнении, долгом нажатии, перетаскивании и смене размера.

**Архив №16: баги с видео (нашла ты)**
- **На странице-стенде** видео-карточки были пустыми, с «0:00», а после перезагрузки страницы видео пропадали — и вместе с ними переставали сохраняться *все* изменения: браузер хранил видео внутри плана, а там место всего ~5 МБ. Теперь фото, видео и файлы стенда лежат в отдельном хранилище браузера (IndexedDB): на карточке кадр из видео и настоящая длина («0:25»), всё остаётся после перезагрузки, видео открывается и играет.
- **«0:00»**: браузер отдаёт длину видео в секундах, а код делил её на 1000, как для iPhone (там миллисекунды). Теперь на iPhone — как было, на стенде — правильно.
- **На iPhone и везде**: если кадр из видео достать не удалось (редкий формат), карточка больше не пустая — тёмная с белым значком ▶ (и в долгом нажатии, и на картинке «Поделиться»). Значок «0:00» больше не показывается.
- На iPhone видео и раньше хранились файлами, без ограничения в 5 МБ; кадр там делает сама iOS. Проверит первая сборка в TestFlight.

**Архив №15: «Включить Pro» в ☰ — только на странице-стенде**
- В ☰ → «Настройки» — строка **«Включить Pro · для проверки»**: Pro включается сразу, без покупки (наверху «Pro», лимита нет, видео можно). Там же «Выключить Pro». Состояние запоминается в этом браузере.
- **В приложении на iPhone этой строки нет** — ни в TestFlight, ни в App Store: Apple отклоняет приложения, где платное открывается без покупки (правило 3.1.1). Новая проверка перед сборкой следит, что в iPhone-версии переключатель выключен.
- **Как попробовать Pro на iPhone** (TestFlight): нажми «Upgrade» → купить. В TestFlight покупка тестовая — деньги не списываются (подписка там продлевается ускоренно и через какое-то время кончается сама).

**Архив №14: исправления по твоей проверке**
- **Подсказка «Это карточки-примеры…»** больше не висит, когда у тебя уже есть свои карточки (была ошибка: она смотрела только, есть ли примеры). Примеры остаются, пока их не уберёшь (☰ → «Убрать примеры» или в шторке Pro), в лимит они не считаются.
- **Период под заголовком** («Ноябрь 2026») — сразу под «Задачи», как подзаголовок: было ~30 pt пустоты, стало 5 pt. Нажимать по-прежнему удобно (44 pt).
- **Нашла и исправила сама**: на закрытом iPhone Duo (узкие карточки рядом с боковой панелью) короткие тексты обрезались — «ХЛЕБ И МОЛ…», «ЗАПИСАТЬСЯ К …». Теперь на маленькой карточке текст целиком (при необходимости чуть мельче, до 10 pt, и чуть выше центра — место под датой), а если он совсем длинный — целые слова и «…» после слова, а не посреди. На iPhone и iPad карточки не изменились: текст ровно по центру, очень длинный обрезается «…» после целого слова.
- В режиме «Изм.» на совсем маленькой текстовой карточке текст прячется, пока не нажмёшь «Готово» (раньше его перекрывали кнопки − / +).

**Архив №13: «Изм.» вместо замка**
- Замок над «+» убран. Вместо него — кнопка **«Изм.»** (по-английски **«Edit»**) вверху слева, как в приложении «Телефон» и в Telegram. Справа в той же строке — «Upgrade», «Поделиться», ☰; крупный заголовок — строкой ниже, во всю ширину (поэтому он больше не уменьшается из-за кнопок).
- Нажала «Изм.» — кнопка становится тёмной **«Готово»**, у карточек − / +, стрелки, размер двумя пальцами. «Готово» — всё закреплено.
- iPhone лёжа и закрытый Duo лёжа (низкий экран): всё в одну строку — заголовок, «Изм.» и кнопки. iPhone Duo: «Изм.» в шапке, в боковой панели снова ☰ · Поделиться · Период.

**Архив №12: замок для размера, подпись сразу, мышь на компьютере** (по отзыву)
- **Замок над «+»** (круглая кнопка, значок как у блокировки поворота). Закрыт — карточки на месте. Нажала — замок открыт (тёмный), у карточек появляются − / + и стрелки, вверху «Готово». Нажала ещё раз или «Готово» — закрыто. Раньше это пряталось в меню («Размер карточек») и в долгом нажатии — человек не нашёл.
- **Размер двумя пальцами**: пока замок открыт, разведи пальцы на карточке — она станет на размер больше, сведи — меньше. Доска в это время не прокручивается. Когда замок закрыт, пальцы ничего не меняют — карточки случайно не «поедут». Переставлять — по-прежнему за стрелки.
- **Открыла фото-задачу — подпись сразу можно писать или менять**: нажми на неё и пиши, как в «Заметках». Пустая — «Добавить подпись». Там же заметка, дата и список. Сохраняется само (через полсекунды и при закрытии). Пустая подпись — просто фото.
- **На компьютере** (страница-стенд): правый клик по карточке — её меню (как долгое нажатие на телефоне); долгое нажатие мышью стало чуть дольше (0,55 с), чтобы обычный клик не открывал меню; при нажатии карточка слегка темнеет — видно, что клик сработал; щипок на трекпаде при открытом замке меняет размер.
- iPhone Duo: замок — в боковой панели (под ☰); на низком экране лёжа — в шапке.
- **Лимит** (проверено тестом): бесплатно — 10 активных карточек. Выполненные и примеры не считаются; удалила или выполнила — место освободилось, можно создавать снова.

**Архив №11: боковая панель на iPhone Duo** (по отзыву тестировщицы)
- На iPhone Duo Apple переносит кнопки приложений в одну вертикальную панель у правого края. Теперь в Pinodi так же: **сверху** меню ☰, «Поделиться» и период; **снизу**, под большим пальцем, — быстрые кнопки **«Текст»**, **«Фото»**, **«Камера»** и большой **«+»** (там же видео и файлы). Текстовая карточка, выбор фото и камера — в одно касание, без лишней шторки.
- Где панель есть: закрытый телефон (внешний экран, стоя и лёжа), открытый в альбомной ориентации, «книга» и «на рёбрах». Открытый вертикально («портрет» и «ноутбук») — как у Apple, обычные кнопки сверху и «+» внизу. iPhone и iPad не изменились.
- Панель никогда не заходит в полосу с камерой (отступ 8 pt от неё) и не стоит на сгибе; карточки заканчиваются за 12 pt до панели — «+» больше не закрывает фото.
- На низком экране (закрытый телефон лёжа) кнопка «Период» уходит первой (она есть и в меню ☰) — все остальные помещаются.
- В шторке текстовой карточки заголовок теперь одним словом — «Текст»: на Duo шторка в половину экрана, и «Текстовая карточка» обрезалась.

**Архив №10: иконка по твоему второму рисунку**
- Те же голубые карточки, но круглее, а карточка с галочкой — графитовая с белой галочкой. Тёмный режим: голубые карточки и светлая с тёмной галочкой; «тинт» — серая версия. Заставка — та же иконка.

**Архив №9: иконка по твоему рисунку**
- Плоская голубая мозаика без теней, карточка с галочкой — светло-голубая, галочка голубая. Перерисована векторно, поэтому края чёткие. Тёмный режим: тёмный фон, голубые карточки; «тинт» — серая версия. Заставка — та же иконка.

**Архив №8: иконка — мозаика, небо** (твой выбор, цвет 4)
- Голубая мозаика вместо терракотовой из №7: светлый, тёмный и «тинт»-вид, заставка — та же иконка. Картинка `Иконка-небо.jpg`.

**Архив №7: иконка — мозаика, терракота**
- Иконка «Мозаика» (три светлые карточки и одна тёмная с галочкой) — теперь терракотовая вместо серо-зелёной. Тёмный режим iPhone: тёмный фон, карточки терракотовые, галочка на светлой. «Тинт» (iOS 18+): серая версия, iPhone сам красит её в выбранный цвет.
- **Заставка при запуске** — та же иконка со скруглёнными углами на светлом фоне (раньше там была прежняя «Карточка с галочкой»).
- Ещё 7 цветов на выбор — картинка `Мозаика-8-цветов.jpg`. Поменять — пара минут.
- Новая проверка перед сборкой: иконки 1024×1024 **без прозрачности** (App Store отклоняет иконку с прозрачностью) и одинаковые в `assets/` и в Xcode.

**Архив №6: фото без подписи, без авто-дат, текст как заметка, Upgrade/Pro, подсказки**
- **Фото без подписи** — просто фото: никакого «Фото-задача» ни на карточке, ни в задаче, ни на картинке «Поделиться». Затемнение снизу появляется, только если есть подпись или дата. Несколько фото сразу тоже без подписей (раньше подписывались именем файла «IMG_2041»); у документов имя файла осталось.
- **Без «Сегодня / Завтра / Вчера»**: у новых задач и у примеров даты нет. Нужна — «Выбрать дату» (в задаче, в заметке, при добавлении), и тогда на карточке стоит число: «7 нояб.». «Убрать дату» — одной кнопкой.
- **Текстовая карточка — как заметка**: нажала — открылся весь текст крупно, можно сразу поправить. Сохраняется само, пока пишешь и когда закрываешь. Под текстом — заметка, дата и список. Сверху галочка «выполнено», «Поделиться», корзина и «Готово». Если стереть весь текст, карточка не потеряется — останется прежний текст (подсказка красным).
- **Поля растут вместе с текстом** — в добавлении, в заметке, в поле «Заметка»: длинный текст видно целиком, а не в маленьком окошке с прокруткой.
- **«Upgrade ›» на всех языках** (по-русски тоже), после покупки на этом месте **«Pro ›»** — открывает «Pro включён» и «Управлять подпиской».
- **Шторка Pro**: добавлена строка **«Без рекламы — ни баннеров, ни роликов»**. Честно: рекламы нет и в бесплатной версии, поэтому это обещание, а не отличие — так и сформулировано, без «уберёт рекламу». Под выгодами, пока на доске есть примеры: «Примеры не считаются в лимит, но их можно убрать сразу — Убрать». Шторка стала плотнее — кнопка покупки видна без прокрутки на обычных iPhone.
- **Подсказка над примерами** на доске: «Это карточки-примеры. Убери их, когда захочешь начать со своих. [Убрать] ✕».
- **Пустая доска**: «Нажми на любое пустое место, чтобы добавить задачу» — и правда, нажатие в любом месте открывает «Добавить задачу» (в пустом списке — задача сразу в этот список).
- **Исправленные баги**: (1) при длинном тексте поле ввода могло бесконечно расти и «ронять» экран в браузере — найдено автотестом, исправлено, на iPhone рост устроен иначе и тоже защищён; (2) в пустом «Выполнено» подсказка отправляла в «Списки», которых больше нет, — теперь «в меню, раздел «Выполнено»»; (3) экран скидки на iPhone Duo «книгой» попадал на сгиб (из №5) — в правой половине.

**Архив №5: меню ☰, уведомления, разовая скидка, ровный текст**
- **Нижней панели больше нет** — ни на iPhone, ни на iPad. «+» плавает справа внизу, под большим пальцем. Всё остальное — в одном меню **☰** справа вверху: списки (сверху), «Эта доска» (переименовать, период, размер карточек, удалить список, убрать примеры) и «Настройки» (уведомления, Pro). Одинаково на всех устройствах. Заголовок iPad больше не открывает списки — они в ☰.
- **Своё название главной доски**: ☰ → Переименовать → например «Задачи на неделю» или «Мои планы». Это же название в списке ☰. Вернуть «Задачи» — одной кнопкой.
- **Текст на карточке ровно по центру**: одинаковый отступ сверху (под галочкой) и снизу (под датой), поэтому блок текста стоит в середине карточки, а не ниже. Строки выравниваются по длине (как на афише), а короткие слова «в», «к», «и», «на» не висят в конце строки — переносятся вместе со следующим словом.
- **Уведомления** (☰ → Уведомления), редкие — не больше одного в день, без рекламы:
  - «Задачи на сегодня» — утром в выбранное время (7, 8, 9, 10 или 12 часов), только если на этот день есть задачи: «Сегодня в планах: Позвонить маме и Хлеб».
  - «Напомнить заглянуть» — одно сообщение, если 3 дня не открывать приложение: «На доске 5 задач. Может, что-то уже можно отметить?». Если открыла — отсчёт начинается заново.
  - «План на неделю» — в воскресенье вечером (по умолчанию выключено).
  - Примеры и выполненные задачи не напоминают о себе. Всё планируется на самом iPhone, ничего не уходит в интернет.
  - Разрешение спрашиваем не при первом запуске, а после первой своей задачи, и сначала объясняем зачем (так советует Apple). Отказалась — больше не спрашиваем, включить можно в ☰.
- **Разовая скидка через 3 недели без Pro**: полноэкранный экран «Год Pro со скидкой N %» с таймером на 60 минут, старая цена зачёркнута, новая крупно; закрывается ✕. Пока таймер идёт, кнопка в шапке показывает «Скидка · 52:13» и снова открывает экран. **Таймер честный**: час начинается один раз, сохраняется и не начинается заново ни после закрытия, ни после перезапуска; после часа скидки больше нет. Это важно: «вечный» таймер, который сбрасывается, Apple считает обманом (правило 5.6) и может отклонить приложение.

**Текстовые карточки и Pro — архив №3**
- **Текст — заглавными, шрифтом Avenir Next** (полужирный), по центру белой карточки. Avenir Next встроен в iOS, поэтому в приложении он бесплатный: файл шрифта в архив не кладём, iPhone берёт свой. (Для сайта или рекламы Avenir пришлось бы покупать — там я его не использую.)
- **Размер шрифта подбирается сам** под карточку: короткое «Хлеб» — крупно, длинный текст — мельче. Слова не рвутся посередине: если слово не влезает, шрифт становится меньше.
- **Много текста:** шрифт уменьшается до 13 pt. Если не влезает и так — показываются строки, которые помещаются, а в конце «…». Полный текст — долгим нажатием (там карточка крупнее) или в самой задаче; кнопка «+» в «Размере карточек» делает карточку больше, и текста видно больше. Лимит — 200 знаков (было 120), чтобы карточка оставалась карточкой, а не заметкой: для длинного есть поле «Заметка».
- В поле ввода тот же шрифт, он уменьшается по мере ввода — сразу видно, как будет на карточке. Клавиатура открывается в режиме заглавных. Сохраняется текст как написан: заглавными он только выглядит, поэтому «Поделиться текстом» отправляет обычный текст.
- То же оформление в меню долгого нажатия и на картинке «Поделиться».
- **«Улучшить ›» / «Upgrade ›»** — тёмная кнопка в шапке, в одной строке с «Поделиться» и «…» (архив №4: раньше была «Перейти на Pro» отдельной строкой со звёздочками). Только в бесплатной версии. По ней раз в ~4 секунды пробегает мягкий блик; если в iPhone включено «Уменьшение движения», блика нет (правило Apple). В режиме размеров и после покупки кнопки нет. По-английски «Upgrade», а не «Update»: «Update» на iPhone значит «обновить приложение».
- **Заголовок шапки всегда целиком.** Если рядом с кнопками ему тесно (iPhone SE, закрытый Duo), шрифт чуть уменьшается; длинное имя списка («Покупки на неделю») уходит строкой ниже кнопок — так делают большие заголовки в iOS. Раньше длинные имена обрезались «…».
- **Новая шторка Pro** (без звёздочек и украшений): картинка из трёх карточек (фото, текст, видео), короткий заголовок в одну строку («Без ограничений»), две выгоды с тем, сколько уже занято («Сейчас занято 5 из 10»), планы **рядом**: «Год» выбран сразу, «Выгода N %» (считается из твоих цен), ≈ цена в месяц, «7 дней бесплатно»; «Месяц» — рядом. Большая кнопка с тем же бликом: «Попробовать 7 дней бесплатно». Под ней: «Потом <цена> в год. Отменить можно в любой момент.» (на стенде цены примерные: 1 490 ₽ и 249 ₽)
- Что Apple проверяет на ревью — соблюдено: самая крупная цифра на плитке — та, что спишут (а не «≈ в месяц»), цена после пробного периода написана под кнопкой, есть «Условия», «Конфиденциальность», «Восстановить покупки» и текст про автопродление. В списке выгод только то, что реально есть в Pro (безлимит и видео); когда выберешь, что ещё добавить в Pro, допишу.
- Мелочи iPhone Duo: закрытый телефон в альбомной ориентации и открытый в альбомной (чётное число колонок) — доведено после стенда №2.

**iPad и iPhone Duo — переделано во второй версии архива**
Сделано по правилам Apple для iPhone Duo (Tech Talks «Design for iPhone Duo», «Strike a pose with adaptive layouts») и для iPad.
- **Нижней панели нет.** Три кнопки внизу на большом экране выглядели скудно, а на Duo Apple вообще убирает панели с центра: на внешнем экране и в альбомной ориентации они уходят на бок, к стороне камеры.
- **«+» справа внизу**, под большим пальцем. «Поделиться» и «…» — справа вверху. Все кнопки вдоль правого края, по центру ничего.
- **Списки — в шторке**: нажми на заголовок «Задачи ⌄» (как переключатель альбомов в «Фото»). Там же «Выполнено» и «Новый список».
- **Доска на всю ширину** (раньше узкая колонка 940 pt по центру). Колонок столько, сколько влезает по ~230 pt: iPad 11″ — 3, 13″ — 4, в альбомной — 5–6.
- **iPhone Duo:** во внутреннем экране в альбомной ориентации всегда чётное число колонок (Apple: так сгиб ложится между ними). «Книга»: по 2 колонки с каждой стороны, на сгибе ни кнопок, ни карточек; шторки и подсказки — справа. «Ноутбук»: панель с тремя кнопками убрана, доска прокручивается сквозь сгиб (Apple это разрешает для прокручиваемого), «+» внизу справа, шторки — в нижней половине. Внешний экран: в полосу с камерой справа ничего не ставим.
- **iPhone не менялся** — там нижняя панель с «+» по центру, как в прототипе. Проверено на всех размерах: SE, 13 mini, 16e, 16 Pro, 17 / 17 Pro, Air, 17 Pro Max и в альбомной.
